## 2. 删除 #dom 公共构造

```diff
@@ 论域输入 @@
- #sat(A,#dom("c))
- #sat(A,#dom(m,a,b))
- 新增公开 DomainNode 和单独的 domain 类别对象。
+ #sat(A,"c)
+ #sat(A,m)
+ #sat(A,m(_,a,b))
+ 第二参数直接表示谓词论域。
+ _ 仅在域模板的首参数位置表示元素槽，其余参数固定。
+ 可用本次操作内的 DomainView 辅助处理，不增加公开 #dom 或存档条目。
```

`m(_,a,b)` 是 v2 为多参数论域保留的简洁输入约定；若只使用一元论域，直接写 `m` 即可。

## 3. 项的 #sat 改为返回项

```diff
@@ #sat 签名 @@
- #sat(A,D)     -> 公式
- #sat(t,z,D)   -> 描述内部值 z 的公式
+ #sat(A,D)     -> 公式
+ #sat(t,D)     -> 项
+ #sat 的输出类别与首参数一致。
+ 删除三参数内部值关系公共接口。
```

```diff
@@ 项的绝对性 @@
- #abs(t,D) 展开为：
- D(t) & ∀z(D(z) -> (#sat(t,z,D) <-> z=t))
+ #abs(t,D) 展开为：
+ D(t) & #sat(t,D)=t
```

公式的 `#abs(A,D)` 仍返回公式，并保留对象自由变量属于域的前提。

## 5. 增加受限的动态参数列表

```diff
@@ 证明期间的元数 @@
```

这不把一个具体谓词变成可变元数谓词，也不允许仅验证一个长度就宣称规则对所有长度成立。

## 7. 展开改为直接推理模式

对于项值 `#sat(t,D)`，不能把定义性质这个公式直接替换到项位置；只有已有定义等式或合法化简依据时才改写源公式，否则使用“生成相对化定义”行动。

## 8. 不再要求 mf 关系唯一

```diff
@@ 函数与常量内部解释 @@
- termDefinitions 注册图关系和外部唯一性证明。
- 需要存在唯一性条件才能作为正常函数项解释使用。
- 对仅按存在关系选择的 mf 符号，首版不自动生成确定解释。
+ 复用原有 mc/mf 选择定义机制。
+ 为新的内部解释符号生成相对化定义。
+ 不要求原关系唯一，也不另设唯一性证书管理。
+ 定义中的存在前提继续保留。
+ 不给原函数直接追加更强的内部性质。
```

例如原常量的关系为 `R(z)`，记相对化后的公式模板为 `R_D(z)`，新内部选择值 `c_D` 的定义形如：

```text
(∃z(D(z) & R_D(z))) > (D(c_D) & R_D(c_D))
```

其中 `R_D(c_D)` 是先相对化、再代入内部值，不是再次对内部值做相对化。

## 15. 保留的最小可靠性检查

精简未删除以下要求：

- 项/公式类别、实际元数、模板及列表绑定一致。
- 变量捕获、不自由出现和量词侧条件。
- 新内部解释的符号新鲜性、稳定性和存在前提。
- 不从任意外部定理自动推出相对化后的结论。
- 新展开必须有合法推理依据，不能覆盖已证明内容。
- 结构归纳分支必须通用，不能用几个实例代替所有公式。
- 旧存档中使用双引号的普通名字保持原义。

这些检查直接决定能否错误地推出结论，不属于被删除的模型管理内容。
